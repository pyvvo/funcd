### ✅ Verified correct (keep it)
- **Contract fidelity is exact** vs `shim/nodejs/src/shim.ts`: `shim/python/src/funcd_shim/shim.py`
  maps dict/list→200 JSON, `None`→204, raise→500 `{error}`, invalid JSON→400, contract mismatch→422
  `{error, details}`; `GET /health/liveness`→200 "ok", `/health/readiness`→200 "ready"; the 422
  `details` carries the validator's `{instancePath, schemaPath}` error list, the same shape the Node
  `jtd` emits. Bind logic matches: `FUNCD_PORT>0` → `0.0.0.0:PORT` else `127.0.0.1:0` + write
  `FUNCD_PORTFILE`. Exit 2 (missing `FUNCD_ARTIFACT`), exit 3 (shape-gate) match.
- **Zero runtime deps + no GPL.** `pyproject.toml` `dependencies = []`; `uv.lock` package set is
  dev-only (mypy, pytest, ruff + transitive) — no `jtd`, no `strict-rfc3339`, no `rfc3339` anywhere.
  Every `jtd` import is the local module (`from . import jtd` / `from funcd_shim import jtd`), never
  the PyPI package.
- **The RFC 8927 validator is a real implementation, not a stub** (`jtd.py`): all 8 JTD forms (empty,
  ref, type, enum, elements, properties/optionalProperties/additionalProperties, values,
  discriminator), integer-bound checks, strict-bool handling, RFC 3339 timestamp via stdlib regex,
  discriminator-tag additional-properties exemption, and `compile_schema` shape-gate raising on
  malformed schemas (one-form rule, unknown keyword, ref-without-definition, mapping-not-properties,
  etc.). `test_jtd.py` asserts real accept/reject verdicts form-by-form.
- **Dispatch** (`function.go` `shimFor` + `WithRuntimeShimFor`): longest family-prefix match,
  `python*`→python shim, else default `shimCommand` (node). Container mode (`EndpointNetnsFixedPort`
  → `imageFor`) is untouched — only the process-mode launch prefix varies. `dispatch_test.go`
  provisions a `nodejs22` and a `python312` function and asserts the exact recorded
  `WorkerSpec.Command` for each.
- **Embed** (`embed.go`): explicit `//go:embed` file list (not `all:`), so no `__pycache__` is
  embedded; `Extract` walks `src/funcd_shim`, writes the tree, and emits a `funcd_shim_entry.py`
  launcher whose dir-on-`sys.path` makes `from funcd_shim...` resolve with no PYTHONPATH.
- **Scenarios all have real, un-skipped, passing tests**: `test_shim.py` covers 200/204/400/500,
  health+404, contract valid / mismatch-with-handler-not-called (proven by a call counter) /
  no-contract, exit 2 / exit 3 via `main()`, and a real `python -m funcd_shim` subprocess proving the
  portfile handshake + loopback bind end-to-end. `test_runtime.py` covers handler/schema resolution
  and shape errors. `runtime-selects-shim` is the Go reconciler test.
- **Typed authoring + py.typed**: `funcd_shim` exports `Handler` / `CloudEvent` / `FunctionContext`
  matching the ADR Contracts; `py.typed` present; the example imports them and typechecks under
  `mypy --strict`.
- **main.go wiring**: extracts the embedded python shim and registers
  `WithRuntimeShimFor("python", python, entry)` when a `python3`/`FUNCD_PYTHON` launcher is found;
  node stays the default; python-absent is a benign info log, node unaffected.
- **Hygiene + tracking**: no local username / filesystem path / email leak in any changed or new file
  (this review doc and the scorecard included). ADR-0049 at `Reviewing`; F12 row links ADR-0049 and
  stays `implemented` (ADR-0049 extends an already-implemented feature). Blueprint Python function
  shape synced to the `handle(context, event)` + `event_schema` reference shim — an Accepted-ADR
  blueprint sync, appropriate. ADR substance is otherwise unchanged.
