The examples live in their own repositories, beside the shims and Apps they use:

| Repository | What it holds |
| --- | --- |
| [funcd-typescript](https://github.com/pyvvo/funcd-typescript/tree/main/examples) | Functions in TypeScript: KV, S3, SQL, workflows, HTTP functions and more |
| [funcd-python](https://github.com/pyvvo/funcd-python/tree/main/examples) | Functions in Python, a Lake example among them |
| [funcd-functions](https://github.com/pyvvo/funcd-functions) | Apps and their functions, such as the todo App |
